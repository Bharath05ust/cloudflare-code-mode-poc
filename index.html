 WHEN IT FITS
Good fit—and important guardrails

          

            
✓
Reach for it when…
  • A task needs several API calls or data transformations
  • The API surface is large and tool definitions use too much context
  • You want to summarize, filter, or join results before returning them
  • Workflows benefit from code-level branching or batching

            
!
Design it carefully
  • Grant least-privilege credentials; separate read and write access
  • Validate inputs and restrict which APIs the runtime can reach
  • Require approval for destructive or production-changing actions
  • Log execution and treat returned data as untrusted input
